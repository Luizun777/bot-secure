# Lecciones aprendidas — {{project}}

Lee esto cuando repitas un error o empieces una tarea parecida a otra. Las lecciones cortas (1 línea) viven en `CLAUDE.md` → "Lecciones aprendidas" (máximo 10); aquí va el detalle y el historial.

Regla de la 2ª vez: si un error ocurre dos veces, se documenta antes de continuar. Si es destructivo o de seguridad, además se propone una guarda (hook o `permissions.deny`).

## Formato
```markdown
### AAAA-MM-DD — título corto
- Qué pasó: (sin valores reales ni datos personales)
- Por qué:
- Qué hacer la próxima vez:
- Guarda propuesta (si aplica):
```
